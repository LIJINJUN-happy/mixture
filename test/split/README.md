# 切包场景测试

在项目根目录运行：

```powershell
go run ./test/split
```

程序直接调用框架的 `DoSplit`，逐项执行原 `test/split_test.go` 的 17 个场景，输出每项 `PASS` 或 `FAIL` 及最终统计；有场景失败时退出码为 1。它测试的是本地切包逻辑，不需要启动服务器。

场景包括完整包、拆包、粘包、跨多次 Read、固定 4096 字节读缓冲与 `readNum=1`、大残包后紧跟下一包、客户端和内部协议的边界长度、非法 `readNum`、输出缓冲不足及单批超过 1024 个包。

客户端包体范围为 2～4094 字节，内部包体范围为 6～4098 字节。长度为 1 或 4095 的客户端包体，以及长度为 5 的内部包体，直接验证 `DoSplit` 返回 false，且不输出非法包。客户端与内部连接分别使用对应的初始化方式。
